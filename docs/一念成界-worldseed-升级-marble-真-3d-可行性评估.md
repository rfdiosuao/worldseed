## 二、四个硬条件（不满足任何一个 → 退回原 2.5D 方案）

| # | 条件 | 判定线 | 不满足的后果 |
|---|---|---|---|
| 1 | **付费档 + 导出权**（Standard 及以上） | 注册后能购 credits、调 API、导 SPZ | 免费档只能拿到 `world_marble_url` 播放器链接，撑不起 three.js 自研渲染，技术故事塌一半 |

| 3 | **现场主路径走预生成缓存** | 缓存秒开是唯一承诺，实时真生成只做背景仪式 | 让评委干等 5 分钟 = 直接劝退 |

## 三、验证过的技术事实（为什么这条路真的走得通）

### 1. 出口没有断
Marble 1.1 生成的世界可导出：
- **SPZ**（2M / 500k 低清两档）→ three.js 用 `gaussian-splats-3d`（兼容 SPZ）加载
- **PLY**（2M / 500k）→ 更通用，`/marble/v1/worlds:<id>:export` 带 `asset_type:splats, format:ply` 即可取到缓存下载链接
- 官方有 Python 客户端 `worldlabsai/worldlabs-api-python` 辅助导出/加载，前端不必从零造轮子

### 2. Draft 模式是降本保底
`marble-1.0-draft` 每次仅 **150 credits（≈$0.12）**，约为标准档的 1/10。适合：
- Day 1 spike 试错（穷测不心疼）
- 现场"专属真生成"收尾（花小钱买仪式感）
- 预生成缓存前的 prompt 调参

### 3. Atlas 是你的升级彩蛋，不是当前依赖
- Atlas 是 World Labs 2026-09-01 发布的**下一代全模态世界模型**，官方明确"**will power future versions of Marble**"——即未来 API 的引擎，不是现在的前置条件。
- 官方开了 **early access 申请表**（"Request early access to Atlas"），但仅限 select partners，未公布标准。
- **拿不到 Atlas 不影响 Marble 路线**；申请纯属白赚的彩蛋，填了不亏，中了就是"全球最早一批用 Atlas 做黑客松"。

## 四、建议的最终方案（调整后的管线）

```
一句话
  → LLM 世界配方（同时输出两样东西）
       ├─ Marble 英文场景 prompt → 定 3D 空间骨架（Marble 负责"空间"）
       └─ 中文 JSON 情绪层：色调/粒子/旁白 → 定"灵魂"（我们负责）
  → 命中预生成缓存（8-12 个按情绪×场景分类）→ 秒开
     未命中 → 异步 Marble 真生成 + "世界孕育中"仪式（流体生长动画 + 旁白逐句浮现）
  → three.js + gaussian-splats-3d 渲染可漫游 Splat
  → 叠加流体氛围粒子 + 旁白 + 交互
  → 封存卡片 + 二维码
```

**三层兜底（保证现场永不黑屏）：**
1. Marble 实时生成（现场专属，异步收尾）
2. 赛前预生成世界库（现场主路径）
3. 原 2.5D 离线版（终极保险，代码保留不删）

**第一版郑重建议砍掉「住民小生物」**——Marble 只生成环境、不含可控角色。把砍掉的工时全押在"可走进的世界 + 封存"这两件最炸的事上。

**成本估算（人民币）：**
- Day 1 spike：5–10 个 draft（$0.12×10 ≈ $1.2）+ 2–3 个标准验证（$3.6）
- 缓存库：8–12 个标准档（$9.6–14.4）
- 现场收尾：2–3 个（draft 亦可，$0.24–3.6）
- **合计约 $15–25，即 ¥110–180**（不含月费档位差异，以计费页为准）

## 六、分工与时间黑洞（谁做什么、防什么）

**两人划分（避免互相阻塞）：**
- **A 技术 Captain**：World API 生成管线 + 缓存匹配 + 仪式化等待 + 兜底切换
- **B 创意编码**：three.js splat 渲染 + 流体/粒子/旁白叠加 + 卡片二维码 + UI

**最大时间黑洞（提前预判）：**
1. **SPZ 浏览器加载调优**——500k 低清档起步，先别 2M；加载进度条与降级
2. **缓存匹配质量**——关键词+情绪标签匹配，别做语义向量（本地跑不动）
3. **仪式化等待的动效打磨**——这是"哇时刻"的一部分，比想象费时
4. **网络环境**——现场若断网，Marble 不可达，三层兜底必须真的能一键切

**现场路演动作（被低估但极加分）：**
- **用评委自己那句话生成**，独一无二、不可彩排——这是最强的记忆点
- 主演示走缓存（秒开），异步真生成在场面定后收尾，避免台上干等

## 八、结论

**有条件可行，方向我建议冲。** 三个原因：
1. 真·可走进的 3D 世界 + 秒开缓存 + 卡片封存，是一个完整且有记忆点的叙事闭环，**对"限制（5 分钟生成）"的优雅处理**正是黑客松评委爱听的故事；
2. 2.5D 视差版在这个赛道是常见套路，差异化弱；Marble 版踩在世界模型最前沿，路演记忆点拉满；
3. 风险可控——**Day 1 的 spike 就是一个内置的"止损闸"**，最坏情况只损失 12 小时，退回 2.5D 方案依然是完整作品。

**动手前 4 件事（按优先级）：**
1. 注册 World Labs → 平台购 $5 credits → 确认 Standard 档含 SPZ 导出 + 现场展示合规
2. 拉 `worldlabsai/worldlabs-api-examples` 跑通官方 web 示例，实测 draft 耗时
3. `.spz` 静态托管用 CDN（Vercel/Netlify），别再想现场本地服务
4. A/B 两成员认领主线，开工

> 最后提醒：所有价格、配额、档位权益以官方计费页（platform.worldlabs.ai / marble.worldlabs.ai/pricing）实时为准。本文档为 2026-09-03 的核实快照。
