> 供编程区 AI 协作使用。**主提示词**作为项目上下文常驻；**单任务提示词**每次贴一条，做完即弃。

## 一、项目主提示词（可粘贴，约 200 字）

```
你是《一念成界 · Worldseed》的技术实现者。项目理念：说一句话，30 秒长出一个能走进去的世界；封存成卡片，寄给那个你想让他懂你的人（Eazo 数字艺术黑客松作品）。

技术方案（已定，勿改架构）：
- 用户一句话 → LLM 世界配方（同时输出给 Marble World API 的英文场景 prompt + 中文情绪层 JSON）
- 命中预生成缓存秒开；未命中异步真生成（约 5 分钟）+ 仪式化等待动画
- three.js + gaussian-splats-3d 渲染 .spz → 叠加流体粒子与旁白 → 封存卡片 + 二维码（零后端 localStorage）
- 三层兜底：Marble 实时 / 预生成世界库 / 2.5D 离线版

硬约束：72h 两人、最小可演示闭环优先、零后端零登录、现场可能断网、主路径必须秒开、移动端适配。
红线：最后 6 小时不加新功能，只修 bug、预生成缓存、彩排。
所有交付物写明文件路径，验收标准可验证，禁止改动已定架构。
```

## 二、Day 1 splat spike 单任务提示词

```
任务：验证 Marble 导出 .spz 能否作为正式渲染层（splat spike），时间盒 ≤6h。

步骤：
1. 用 World Labs API 生成 3 个试验世界（文本 prompt，覆盖：室内/室外/夜景三种场景）。
2. 每个世界导出 .spz（500k 低清档起步），保存到 worldseed/spikes/day1-splat/output/worlds/{id}.spz。
3. 写一个最小 three.js + gaussian-splats-3d 加载页（本地离线可跑），可漫游、可鼠标交互。
4. 移动端适配检查（375px 视口）与 WebGL 能力探测。

验收标准（全部可验证，证据写入 worldseed/spikes/day1-splat/output/report.md）：
- 质感：3 个世界均成功渲染，截图为证 output/screens/{id}.png（每个至少含一个完整主体；任一加载失败或大面积空洞即不达标）。
- 导出：3 个 .spz 真实存在 output/worlds/{id}.spz，大小与来源记录于 output/manifest.json。
- 流畅：桌面 Chrome 60s FPS p50 ≥ 30 且 p95 ≥ 20（记录于 output/fps.json）；任一项低于阈值即不达标。
- 秒开：离线本地服务器下，点击到首帧 ≤ 3s（缓存命中 ≤ 800ms），记录于 output/startup.json。
- 断网复验：关网重启 dev/preview 后上述全项复测通过，复测记录入 report.md。

决策点：达标 → 本链路定为正式渲染层；不达标 → 当日回退 2.5D 离线版。
决策与数据记入 worldseed/decision-log.md 及 worldseed/spikes/day1-splat/fallback-2.5d.md。
spike 失败 ≠ 项目失败——它是 Day 1 的漏斗，数据进 decision-log 后团队只认结论，不回头争论。
```

## 三、蜂群 / delegate 决策口诀

> **读并行用蜂群，写独立用 delegate，耦合代码自己动手。**

| 场景 | 用哪个 | 原因 |
|---|---|---|
| 写代码、跑构建、调 bug | 都别开 | 蜂群只读、子代理无 shell；开发是串行闭环 |
| 预研调研、读代码理解、多方案对比、代码审查 | 蜂群 ✅ | 只读环节，并行省时 |
| 独立模块开发（工具函数/独立组件/数据脚本） | delegate ✅ | 配工具白名单直接产出可运行代码 |
| 入口文件、package.json、公共类型、共享组件 | 主代理自己写 | 谁的文件谁写，绝不交叉，冲突靠划界解决 |

**蜂群性价比前提**：要求子代理输出结构化摘要（按文件列要点），减少主代理二次读取。
