# 一念成界 · Worldseed

> **说一句话，30 秒长出一个只属于你、能走进去的世界；封存成卡片，寄给那个你想让他懂你的人。**

参赛：Eazo 数字艺术黑客松（赛道③创新互动，兼容①书籍可视化）｜ 推荐人数：2 人（冲顶 3 人）

---

## 这是什么

一个把「脑海里说不出口的世界/情绪」变成**可进入、可交互、可分享**的微型世界的网页作品。

用户输入一句话（或对着麦克风说），例如「我想回到外婆家那个下着雨的夏天」，系统在 3–5 秒内让一个场景从无到有「生长」出来：天色、地貌、雨、光、一个呼吸着的小住民，鼠标移动时世界随之视差流动。最后可把这个世界**封存成一张卡片 + 二维码/链接**，寄给另一个人，对方点进来就能「走进你刚才的脑海」。

核心闭环（演示路径）：**输入一句话 → 世界生长（哇时刻）→ 进入并交互 → 封存成卡片 → 二维码带走/寄出**。

## 技术升级（v2 方案）

用 **World Labs World API（Marble）** 把原方案的「2.5D 三层图视差」升级为**真·可走进的 3D 世界**：

```
一句话
  → LLM 世界配方（Marble 英文场景 prompt + 中文情绪层 JSON）
  → 命中预生成缓存 → 秒开 / 未命中 → 异步真生成 + 仪式化等待
  → three.js + gaussian-splats-3d 渲染可漫游 Gaussian Splat
  → 叠加流体氛围粒子 + 旁白 + 交互
  → 封存卡片 + 二维码（零后端）
```

**三层兜底（现场永不黑屏）：** Marble 实时生成 → 赛前预生成世界库 → 原 2.5D 离线版。

## 技术栈

- 前端：Vite + 原生 JS / React，响应式与移动端适配
- 渲染：three.js + gaussian-splats-3d（.spz Gaussian Splat）
- 生成：World Labs World API（Marble 1.1 / 1.0-draft）
- AI：豆包 / OpenAI API（世界配方）
- 分享：URL 参数压缩编码 + qrcode.js + localStorage（零后端）
